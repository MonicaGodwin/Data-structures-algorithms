# Data Structures & Algorithms

This repository contains my solutions to **Data Structures and Algorithms (DSA)** problems as I learn and improve my problem-solving skills.

The goal of this repository is not just to solve problems, but to understand **how to think through problems, choose appropriate data structures, and write efficient solutions**.

## Goals

Through this repository, I aim to:

* Improve my problem-solving skills
* Strengthen my understanding of data structures
* Learn different algorithms and when to use them
* Practice writing clean and readable code
* Understand time and space complexity
* Become more confident solving problems independently

## My Approach

For each problem, I try to follow these steps:

1. Understand the problem.
2. Identify the inputs and expected output.
3. Break the problem into smaller parts.
4. Think about possible approaches.
5. Write the solution.
6. Test it with different examples.
7. Analyze the time and space complexity.
8. Review and improve the solution when necessary.
